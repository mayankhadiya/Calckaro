# CalcKaro

CalcKaro is a static collection of browser-based Indian finance calculators deployed at [calckaroindia.netlify.app](https://calckaroindia.netlify.app/).

## Available calculators

- SIP projection with optional annual step-up
- Old versus New income-tax estimate for FY 2025–26 / AY 2026–27
- Home-loan EMI and amortization estimate

Calculator inputs are processed in the browser. The contact form is handled by Netlify Forms.

## Traffic and monetization

Repository stars, forks and watchers are software-project signals, not website visitor counts. Website discovery and usage should be checked in Google Search Console and a deliberately configured analytics service. Advertising should only be enabled after AdSense approval, a real publisher ID, required consent configuration and a matching privacy policy.

See [LAUNCH-CHECKLIST.md](LAUNCH-CHECKLIST.md) for external setup that cannot be completed from source code alone.

## Financial-content maintenance

Rules and rates change. Keep a visible supported period, assumptions, official sources, last-reviewed date and correction path. Never change only a year label without verifying the underlying logic and copy.
