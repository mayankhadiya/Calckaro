# CalcKaro

Static HTML/CSS/JavaScript finance calculator site for India, deployable on Netlify.

## Live calculators in this repository

- `sip-calculator.html`
- `income-tax-calculator.html`
- `home-loan-emi-calculator.html`

## Supporting pages

- `index.html`
- `about.html`
- `contact.html`
- `privacy-policy.html`
- `disclaimer.html`
- `404.html`

## SEO/hosting files

- `_redirects`
- `robots.txt`
- `sitemap.xml`

## Optional integration templates (not active by default)

- `ads.txt.example`
- `analytics.example.html`

## Deployment

This project has no build step and no dependencies.

1. Push to GitHub.
2. Connect the repository to Netlify.
3. Deploy as a static site.

## Important manual tasks (owner account required)

See [`LAUNCH-CHECKLIST.md`](./LAUNCH-CHECKLIST.md) for:

- Search Console setup and sitemap submission
- Domain/canonical verification
- Optional analytics setup
- AdSense approval and `ads.txt` activation
- Post-launch QA checklist

## Financial content maintenance

- Time-sensitive assumptions (especially income-tax and lender-rate references) must be reviewed before yearly updates.
- Do not change tax slabs/rules without verifying official sources.
- Keep visible “last reviewed” notes up to date when updating assumptions.
